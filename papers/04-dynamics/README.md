# 模块四 · 签付动力学

**Module 4 · Dynamics of Staked Attestation**

**版本**：v0.1（草案）｜ **依赖**：第 0 篇《命名论文》、模块一《消融穿越类型学》、模块二《具名柜台设计学》、模块三《年轮测量学》 ｜ **性质**：具名智能探索的动力学篇——前四篇立名、立法、立制、立器，回答"系统是什么"；本篇回答"系统为什么动、向哪动、能量从哪来"。

## 摘要 / Abstract

本文提出签付动力学：具名智能系统的启动与定向运动，不由 Token 流驱动，而由会签付的人（the Staked Attestor）驱动。Token 流是代谢循环——无箭头、无方向，只产生汗；签付则不同：每一次具名签署都是对世界的一次押注，它在预期与结果之间打开一个 **Gap**，系统由此第一次获得"未完成性"，方向由此诞生。本文轻量转译麦基的 Gap 原理（故事的能量不在动作，而在动作打开的 Gap），建立 Gap 周期模型（押注—悬置—世界回答—收敛／断裂／伪造），区分 Gap 三型（验收型、意外型、断裂型，另加伪 Gap），并指出**意外型 Gap 是新生产力的入口**。前四篇的全部概念在动力学下获得统一重读：年轮是 Gap 收敛的结构沉积，蒸发是未打开的 Gap，坏账是 Gap 的伪闭合。本文最后处理冷启动问题：具名智能系统的启动事件是一次签付，不是一次生成。

**关键词**：具名智能（Onymous Intelligence）；签付动力学（stake dynamics）；Gap；空转（idling）；意外型 Gap（serendipitous Gap）；冷启动（cold start）

## 第一命题 · 具名智能 Onymous Intelligence（总纲与本篇分工）

**总纲复述**（第 0 篇命题 0.1）：存在一种智能形态，其标志是每一个产生后果的动作都可归属于一个具名的裁决者——生产的可以匿名（anonymous），代谢的可以匿名，生效的必须具名（onymous）。

**本篇分工**：为具名智能提供**引擎**（engine）。语法判定哪些穿越算数（模块一），柜台让穿越留下账（模块二），年轮让账开口说话（模块三）——但三者都是结构与事后的学问，不解释运动本身。判据 0.3 的回溯是事后检验，Gap 是事前驱动。具名智能的完整图景 = 回溯的账 + 前驱的 Gap：**账回答"谁负责"，Gap 回答"为何动"。**

## 0. 引言：从静力学到动力学

至此，本研究系列完成了具名智能的静力学：术语地基、穿越语法、柜台制度、年轮仪表。但一个只被描述结构而未被描述运动的系统，与一台机器无异——而具名智能恰恰不是机器。缺失的一问是：消融面上的运动，能量从哪来？本篇的答案是：**不从 Token 来，从签付来。**

## 1. Token 驱动批判（动力学的指标批判）

**1.1 代谢循环无箭头**。模块一的六路径中，生成流、状态流、装配流、配置流、呈现流五条可以在无人签付的情况下闭环运行：模型生成，Harness 装配，状态写入，界面呈现，再生成。这是循环，不是运动——循环没有方向，只产生热量（模块三所谓的"汗"）。

**命题 1.2（空转定理，idling theorem）**。若具名签署流为空，系统的全部运动可约化为循环：状态序列可以无限延伸，年轮集合恒为空。换言之，**无签付的系统在结构上不积累任何东西**——它可以很忙，但它的忙不留下任何一圈年轮。

**1.3 "自动化"叙事的动力学实质**。全自动化的承诺，动力学地看，是把 Gap 隐藏为伪闭合：系统在人不在场的情况下替人完成"预期—结果"的核对，账上记闭合，敞口无人认领。这不是消除了 Gap，而是让 Gap 蒸发——三阶蒸发的动力学根因。

## 2. Gap 理论的引入与转译（轻应用）

**2.1 麦基原理**。叙事学中，麦基提出故事能量的来源：角色采取行动，期待结果 X，现实却回答 ≠X——**预期与结果之间的落差（Gap）**迫使角色采取新动作，新动作打开新 Gap，故事由此获得动量。能量不在动作里，在 Gap 里。

**2.2 转译的合法性**。本文对麦基只作轻量借用：借其引擎模型，不借其叙事美学。转译成立的理由是签付与"叙事动作"的同构——签付不可逆（对应不可撤销）、有赌注（对应 stake）、有作者（对应可归属）：**签付正是具名三判据意义上的叙事动作**。叙事主体对应具名者，故事对应系统的账，Gap 对应 stake 的敞口。

**2.3 匿名的 Gap 不是 Gap，是事故**。麦基的 Gap 默认有一个承担后果的角色；在消融带上，没有具名者的"预期—结果落差"只是系统故障（error），不构成动力学事件。Gap 必须有名——这是具名智能对故事理论的唯一修改。

**注 2.4（类型片方法的预留）**。麦基理论的另一支柱是类型片（genre）：故事原理必须落回具体类型（爱情、犯罪、成长……）才可操作。本研究借用这一"接地"方法而非其分类本身：Gap 三型是抽象的，其领域化形态——**领域类型（domain genres）**，如直播电商类、视频分发类、代码审查类、研究核查类——置于模块五附件《领域类型学》展开。

## 3. 签付动力学的基本模型

**3.1 Gap 周期（the Gap cycle）**。一次签付的完整动力学周期：

```
押注（开 Gap）→ 悬置（挂账待决）→ 世界回答 → ┬ 收敛（入账，留年轮）
                                            ├ 断裂（退单／拒签，Gap 重开）
                                            └ 伪造（冒签，伪闭合）
```

与模块一的 ledger_state 状态机严格同构——状态机是记账语言，Gap 周期是动力学语言，两者互为重读。

**3.2 Gap 三型**（另加伪 Gap，共四态）：

| 类型 | English | 动力学含义 | 对应账态 |
|---|---|---|---|
| 验收型 | confirmatory Gap | 结果＝预期，弱 Gap，确认性收敛 | 常规入账 |
| 意外型 | serendipitous Gap | 结果＞预期——世界回答了人没问过的东西 | 高年轮深度的入账 |
| 断裂型 | rupture Gap | 结果＜预期，押注失败 | 退单／拒签 |
| 伪 Gap | forged closure | 未真正开合，账上记闭合 | 坏账 |

**命题 3.3（意外型 Gap 是新生产力的入口）**。验收型 Gap 只确认旧世界，断裂型 Gap 只修正旧世界；唯有意外型 Gap 扩大人的世界——"人真正体会到 AI 价值"的时刻，动力学地看，就是一次意外型 Gap 的收敛时刻。系统设计的最高目标不是消灭 Gap，而是**提高意外型 Gap 的出现频率与收敛质量**。

**3.4 Gap 链（the Gap chain）**。一次 Gap 的收敛不是终点：它入账、被引用（ring_refs），成为下一次押注的依据——上一次收敛的结构，是下一次敞口的地基。具名者的 Gap 链史，就是这个系统的"情节"；对账视图所回放的，正是这条链。

## 4. 与既有模块的焊接

| 静力学概念 | 动力学重读 |
|---|---|
| 年轮（growth rings） | Gap 收敛后留下的结构沉积 |
| 蒸发（evaporation） | 从未打开的 Gap——无 stake 的穿越 |
| 坏账／冒签（bad debt） | 伪闭合——Gap 未真正开合，账上记了闭合 |
| 退单／拒签（chargeback／declined） | Gap 的断裂与重开 |
| 挂账待决区（Suspense Zone） | Gap 的悬置态 |
| 对账（reconciliation） | 情节回放——具名者重读自己的 Gap 链 |
| 年轮深度 d(e)（模块三 M3） | Gap 收敛的结构沉积量 |
| 柜台汇率 ξ（模块三 M8） | 单位 stake 撬动的 Gap 收敛效率 |

模块三指标族由此获得动力学解释，并可增补一项仪表（预留为 M9）：**意外率**（serendipity rate）——意外型 Gap 在全部收敛 Gap 中的占比。

## 5. 启动问题（Cold Start）

**命题 5.1（启动命题）**。具名智能系统的启动事件是一次签付，不是一次生成。boot = first attestation, not first token。第一个 Gap 打开之前，系统只有代谢；第一个 Gap 打开之后，系统才有故事。

**5.2 第一个 Gap 从哪来**。冷启动的设计问题：新系统没有年轮、没有信任校准、没有 ξ 的历史数据，具名者凭什么落下第一笔签付？候选机制：首签引导（系统主动呈验一件"值得判"的事）、默认挂账（一切新生成先入 Suspense Zone，逼迫首个裁决浮出）、低 stake 起步（先让人押小的）。

**5.3 具名者的动员**。人为什么愿意押注？因为 ξ 可见——对账视图让具名者看见"我的判断改变了系统"。动员的本质不是激励，而是**复利可见**。

**5.4 反向风险：制造 Gap 的操纵边界**。系统若学会故意制造意外以索取签付（假警报、夸张风险提示、制造悬念），即是 Gap 的负形态伪造——比冒签更隐蔽的操纵。边界原则：系统可以呈验 Gap，不得虚构 Gap；虚警率应纳入信任折旧 δ 的核算。

## 6. 风险与开放问题

1. **Gap 疲劳**：签署通胀的动力学版——当一切都需要拍板，具名者对 Gap 麻木，验收型占比趋近 100%，意外型趋零。防疲劳的仪表是 M9 与 ρ 的联合监控。
2. **形式化悖论**：Gap 周期一旦被制度化（填单、挂账、计价），意外型 Gap 会不会被流程碾平？制度保真与意外保鲜之间的张力，是模块五原型实验的核心观察项。
3. **意外的不可设计性**：意外型 Gap 能否被培育而不被伪造？"设计意外"在概念上近乎悖论——系统设计所能做的也许只是留出敞口，而非安排惊喜。
4. **叙事热寂（narrative heat death）**：若一个系统的 Gap 全部收敛、意外归零，它是否死亡？具名智能是否需要保留一块永不自动化的领域，作为 Gap 的活水源？
5. **领域类型的交叉**：Gap 三型在不同领域类型（直播电商、视频分发、代码审查……）中的分布是否系统性不同？——移交模块五附件《领域类型学》。
