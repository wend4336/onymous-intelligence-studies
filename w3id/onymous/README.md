# /onymous/ — Onymous Intelligence Studies

Persistent URIs for the terminological system of **Onymous Intelligence Studies (具名智能探索)** — the naming, typology, institutional design, metrics, dynamics, and monetary layer of onymous intelligence (the strict counterpart of Embodied Intelligence: embodiment brings intelligence into the physical world; onymity brings it into the world of responsibility).

Redirects resolve to the canonical definitions in the naming repository:
https://github.com/wend4336/onymous-intelligence-studies

## Examples

- `https://w3id.org/onymous/` → naming declaration (README)
- `https://w3id.org/onymous/attestation` → glossary entry for attestation（具名签署）
- `https://w3id.org/onymous/ablation-zone` → Paper 0, Definition 2.1
- `https://w3id.org/onymous/TraversalEvent` → formal spec
